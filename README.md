# spain-ppa-intermediary

Research on access to Spain's corporate power purchase agreement (PPA) market, and on whether a public tripartite intermediary could open it to buyers who are currently excluded: SMEs, small consumers, and energy-intensive industry with flat demand.

## Structure

| Folder | Contents |
|---|---|
| `data/raw/` | Original downloads (not edited) |
| `data/interim/`, `data/processed/` | Cleaned data produced by code |
| `config/` | `assumptions.yaml`: model assumptions with sources |
| `R/` | Reusable R functions |
| `analysis/` | Analysis scripts, run in numbered order |
| `outputs/` | Figures and tables |
| `literature/notes/` | Reading notes |
| `paper/` | Quarto manuscript |

## Running the analysis

Requires R (≥ 4.3). Open the folder in Positron and run the scripts in `analysis/` in numbered order.
